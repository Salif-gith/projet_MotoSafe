# projet_MotoSafe
MotoSafe est un système de sécurité électronique intelligent destiné à protéger les motos contre le vol. Le dispositif détecte les tentatives de déplacement ou de manipulation non autorisée via un capteur de vibration, bloque électroniquement le démarrage en coupant le circuit CDI grâce à un relais, et alerte le propriétaire par SMS
