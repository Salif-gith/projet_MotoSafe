# projet_MotoSafe
MotoSafe est un système de sécurité électronique intelligent destiné à protéger les motos contre le vol. Le dispositif détecte les tentatives de déplacement ou de manipulation non autorisée via un capteur de vibration, bloque électroniquement le démarrage en coupant le circuit CDI grâce à un relais, et alerte le propriétaire par SMS. Une application mobile permet d’activer ou désactiver le système et de déclencher une alarme sonore à distance.

Le prototype est conçu pour être compact, discret et facile à installer sur la plupart desmotos courantes au Burkina Faso. Il s’appuie sur des technologies open-source (Arduino) et sur un module Bluetooth(ou module GSM) pour la communication.
                                    
                                    Technologies employées
• Microcontrôleur Arduino Nano : gestion des capteurs, relais et communication.
• Module GSMSIM800L :envoi/réception de SMS pour alertes et commandes.
• Capteur de vibration SW-420 : détection des mouvements suspects.
• Relais 12V : coupure du circuit CDI pour empêcher le démarrage.
• Buzzer 5V : alarme sonore activable via application mobile.
• Application mobile (Bluetooth) : interface utilisateur pour activer/désactiver le
système et déclencher l’alarme.

                                  Pertinence, impact et innovation
• Pertinence : Répond directement à une problématique sociale et économique importante au Burkina Faso (vol de motos).
• Impact : Protège les biens des citoyens, améliore la sécurité urbaine, peut réduire le taux de vols.
• Innovation : Combinaison originale de blocage électronique, alerte SMS et application mobile adaptée au contexte local (fonctionnement sans Internet).
Utilisation intelligente des ressources du Fablab (impression 3D boîtier, prototypage électronique).
